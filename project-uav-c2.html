Hardware-Rooted Secure Communication Architecture for UAV Command & Control Using Multi-Bit RO-PUF, AES-128, and HMAC-SHA-256 on FPGA

Kavin M · Dr V. Jeyalakshmi · P. Varalakshmi — manuscript in preparation, 2026

A lightweight, hardware-rooted security architecture for UAV command-and-control links. A challenge-controlled multi-bit Ring Oscillator PUF generates device-unique key material with no key stored in non-volatile memory; the response is whitened by SHA-256, used to key AES-128 encryption and an HMAC-SHA-256 integrity tag, with a 32-bit hardware packet counter blocking replay. Implemented as the Ground Base Station transmitter on a Xilinx Artix-7 FPGA (Basys 3).

01

Architecture

Ground Base Station transmit data path. A challenge issued by the UAV drives the RO-PUF; its 128-bit response is concatenated with the payload and passed through SHA-256 to derive a session key. The lower 128 bits key AES-128 encryption; the full 256-bit digest keys the HMAC-SHA-256 tag computed over the ciphertext and packet counter — an Encrypt-then-MAC pipeline that ensures the receiver never processes unauthenticated ciphertext.

Ground Base Station transmit-side data path — RO-PUF → SHA-256 key derivation → AES-128 encryption → HMAC-SHA-256 (Encrypt-then-MAC) with replay-protecting packet counter.

Synthesized on a Xilinx Artix-7 (XC7A35T-1CPG236C, Basys 3) in Vivado 2017.4, using slice logic only — no dedicated Block RAM or DSP resources, which keeps the design portable to smaller UAV-grade FPGAs.

03

Output — VIO Hardware Validation

Functional correctness was verified on-chip with a Virtual Input/Output (VIO) debug core across ten randomized 128-bit challenge vectors, confirming the full progression from raw PUF entropy to the final authenticated, encrypted packet.
